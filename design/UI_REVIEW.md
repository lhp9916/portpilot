# PortPilot UI 设计审阅意见

## 审阅范围

基于 `design/preview-dark.png`、`design/preview-light.png`、`design/preview-1100x720.png` 和 `design/UI_SPEC.md` 进行审阅。

## 优点

- 整体视觉方向正确：冷静、专业、不花哨，符合网络工具气质。
- 深浅两套主题色板完整，无明显断层。
- 规则列表卡片信息密度和可读性平衡得当，协议标签、状态点、迷你趋势线清晰。

## 改进建议

按优先级从高到低排列：

### P1 高优先级

1. **操作入口缺失**：最关键操作是"启动/停止规则"，但列表卡片行尾没有直接启停按钮，用户必须先选中再去右侧操作。建议在每张规则卡片行尾添加小型启停切换按钮（play/stop），悬停或选中时显示，避免视觉干扰。
2. **详情头部操作优先级**：右侧详情头部把"重启/停止"放在最显眼位置，但"重启"不应与"停止"同级。建议"重启"降级为次级按钮样式，或移入更多菜单。
3. **连接路径模块视觉重量偏大**：占大量垂直空间但信息量不如统计卡。建议压缩高度至约 `110px`，或将统计卡提前到路径图之前。

### P2 中优先级

4. **速率单位不一致**：列表中混用 `MB/s` 和 `KB/s`，累计流量混用 MB/GB。建议统一自动进位逻辑（B/s → KB/s → MB/s），图表 tooltip 使用同一体系。
5. **图表缺 Y 轴刻度**：实时流量图只有 X 轴时间标注，无法判断速率绝对值。建议在左侧添加 2-3 个 Y 轴刻度，或在图表头部显示当前峰值。
6. **图表 tooltip 位置**：右上角 `1.1 MB/s` 浮标直接压在折线上。建议移到图表头部副标题旁或图表左上角固定位置。
7. **协议标签颜色语义**：UDP 使用琥珀色与"警告"语义冲突（UDP 不是警告）。建议浅色主题下 UDP 标签改用更中性或更亮的色彩，深色主题可保留琥珀但降低饱和度。
8. **列表行内操作缺失**：除启停外，建议每张卡片悬停时显示"复制地址"和"更多"按钮，提高多规则管理效率。

### P3 低优先级

9. **端点健康卡价值偏低**：目标延迟等信息实用但优先级低。建议把目标延迟合入统计卡区域（如活跃连接卡下方加"平均延迟"），健康卡简化或移除。
10. **左侧导航版本号竖排**：桌面应用少见竖排文字，egui 实现成本也高于横排。建议改为横排小字号版本号。
11. **弹窗表单缺校验状态**：原型未展示校验失败状态。建议补一版错误状态预览，或至少在设计规范中定义错误提示样式（红色边框 + 字段下方错误文字）。
12. **图表装饰效果实现成本**：深色主题下渐变、光晕、路径脉冲在 egui 中自绘成本较高。建议 egui 版主动降级：去掉渐变光晕，保留状态点、边框、间距和圆角，靠排版层级建立视觉层次。
13. **双栏滚动行为**：`1100x720` 下右侧内容被裁切属正常，但规范应明确"右侧详情区独立滚动，不与左栏联动"。

## 总结

设计已达到可进入 egui 实现的程度，不需要大改。优先处理 P1 的三条（行内启停按钮、详情操作优先级、连接路径压缩），P2/P3 可在实现过程中逐步优化。
