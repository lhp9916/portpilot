# PortPilot 界面设计规范

## 设计方向

PortPilot 是本地网络工具的“控制台”，视觉上强调精确、安静和可观察性，而不是游戏化或强科技霓虹。

- 核心气质：可信、清晰、低干扰。
- 主色使用青绿色，表示“连接正常”；蓝色用于目标端和下行流量，紫色仅用于区分 UDP。
- 深色主题为默认展示主题，同时提供完整浅色主题。
- 使用细边框、扁平卡片和少量局部光晕，避免重渐变、毛玻璃堆叠和复杂动画。
- egui 实现不使用自绘标题栏，保留系统原生窗口边框。

## 布局

- 基准窗口：`1100x720`，最小窗口：`980x680`。
- 左侧导航栏：`76px`，包含品牌标志、规则/日志/设置入口和运行状态。
- 主内容区：顶部工具栏 `82px`，下方为规则列表与规则详情双栏。
- 规则列表：`390px`，窗口变窄时压缩至 `340px`。
- 详情区：剩余宽度，最小 `560px`。
- 页面外边距：`16-20px`；卡片间距：`9-12px`；面板圆角：`12-16px`。

## 字体与字号

- 中文 UI：Noto Sans SC；Windows 原型阶段回退系统 UI 字体。
- 地址、端口、速率、时间：Cascadia Code / Consolas 等等宽字体。
- 页面标题：`23px / 650`。
- 规则详情标题：`20px / 650`。
- 普通正文：`12-12.5px / 400-600`。
- 辅助标签：`9-10px / 400-600`。
- 地址和统计数字：`9-16px` 等宽字体。

## 组件

### 左侧规则卡片

- 第一行：协议标签、规则名、状态点与状态文字，行尾提供启停快捷按钮。
- 第二行：`本地地址:端口 → 目标地址:端口`，地址使用等宽字体。
- 第三行：实时速率、活跃连接/会话、迷你趋势线；悬停或选中时趋势线切换为“复制地址 / 更多”操作。
- 选中态使用左侧 `2px` 青绿指示条、渐隐底色和强化边框。
- TCP 标签使用蓝色，UDP 标签使用紫色；琥珀色只用于警告。

### 详情头部

- 第一行：协议、状态、启动时间。
- 第二行：规则名称和状态摘要。
- 右侧操作：复制地址、更多菜单、停止。重启、复制规则和删除规则收纳进更多菜单。
- 停止是运行状态下的主要操作，使用低饱和红色按钮；重启不与停止同级展示。
- 不使用大面积彩色背景，让内容本身成为视觉重点。

### 连接路径

- 使用两个端点卡片和中间虚线连接表示转发路径，模块高度压缩至约 `90-100px`。
- 本机监听使用青绿，目标服务使用蓝色。
- 中间运动点仅用于强调正在传输，egui 版本可改为静态箭头或低频脉冲。

### 统计与图表

- 四个统计卡展示上下行速率、活跃连接和累计流量，活跃连接卡同时显示平均延迟。
- 流量图使用双折线，青绿为上行、蓝色为下行；上行带低透明度面积。
- 图表左侧提供 4 档 Y 轴刻度；当前值和 60 秒峰值放在图表头部，不使用压线的浮标。
- 图表坐标和卡片标签使用低对比度，数据使用高对比度。
- 速率统一按 `B/s → KB/s → MB/s → GB/s` 自动进位，字节量同理；同一视图中保留一位小数，数值达到三位后减少小数位。

### 日志

- 日志使用“时间 / 级别 / 消息”三列，详情区展示最近 7 条，完整日志进入日志页。
- WARN 使用琥珀色，ERROR 使用红色。
- 目标延迟合入统计卡，不再单独占用端点健康卡。

### 新建规则弹窗

- 宽 `510px`，圆角 `16px`，包含名称、协议、地址、端口、目标地址和“创建后立即启用”字段。
- 协议使用 TCP/UDP 分段控件。
- 监听地址使用下拉选择，只展示回环地址和本机具体网卡地址。
- 弹窗底部固定取消、创建按钮；创建按钮使用主色。
- 校验失败时字段显示红色边框，字段下方显示具体错误原因；错误态使用 `design/preview-validation.png` 作为视觉基准。

## 状态与动效

- `Stopped`：灰色状态点。
- `Starting`：青绿色状态点 + “启动中”。
- `Running`：绿色状态点。
- `Stopping`：灰色状态点 + “停止中”。
- `Failed`：红色状态点，详情头部显示错误摘要。
- 动效仅用于状态变化、连接路径脉冲和悬浮反馈；持续动画控制在低频，不干扰阅读。

## egui 落地建议

- 使用 `egui::Frame` 实现面板、卡片和圆角；颜色集中到 `Theme` 结构体。
- 双栏使用 `SidePanel` + `CentralPanel`，规则列表用 `ScrollArea` + 自定义卡片。
- 趋势图和吞吐图使用 `egui_plot`，小型趋势线也可用 `egui::Painter` 绘制。
- 状态点、协议标签、统计卡实现为可复用小组件。
- 新建规则使用 `egui::Window` 或 `egui::Modal`，表单校验错误直接显示在字段下方。
- 图标使用内嵌 SVG 转换后的 egui 纹理，或使用单色 PNG 图集；避免依赖系统 emoji 字形。
- 中文使用内嵌 Noto Sans SC 字体；地址和数字使用 Cascadia Code 或等宽回退字体。
- 浅色/深色主题切换时，所有自定义颜色必须从主题对象获取，不能硬编码。
- 规则列表和详情区各自独立滚动，互不联动；紧凑窗口中详情区内容滚动时，左侧选中项保持固定。
- egui 版主动降级装饰：去掉大面积渐变光晕、路径脉冲和图表阴影，保留边框、圆角、状态点和排版层级。
